MyMule

A light client for the eMule network, eD2K and Kad, written in Go. One small binary with no dependencies, for Windows, Linux, macOS, FreeBSD, ARM boards and NAS devices, using about 15 MB of RAM.

Install Source on GitHub Documentation

Use it the way that suits you

Web interface

Downloads, searches, sharing and servers from any browser, phone included. Search movies and series by title and get their files scored by language and quality.

Command line

A background daemon with short commands, and mymule top, a live full-screen view where you can also search and manage downloads.

Radarr, Sonarr and friends

A Torznab indexer and a qBittorrent-compatible download client, so eD2K becomes one more source for Radarr, Sonarr, Lidarr, Readarr and Prowlarr.

HTTP API

A small JSON API for scripts: PHP, Python, shell, cron jobs and home automation.

Features

  • Searches on the connected server or on every known server at once, and on Kad.
  • Kad, the network without servers: searches and sources there too, your shared files published, and a full Kad node for others.
  • MD4 verification of every 9.28 MB part: corrupt parts are downloaded again, and peers that keep sending bad data are dropped.
  • Sharing and uploads with a queue, slots taken in turns and a speed limit.
  • Resume after a stop, a crash or a reboot.
  • HighID support, server callbacks and Kad buddies to reach firewalled peers.
  • Everything other peers and nodes send is checked and bounded.

Install

Docker

Any system with Docker, including NAS devices and Raspberry Pi (amd64, arm64 and armv7). In an empty folder:

docker run -d --name mymule --restart unless-stopped -e PUID=1000 -e PGID=1000 -v ./config:/config -v ./downloads:/downloads -p 4662:4662/tcp -p 4672:4672/udp -p 4711:4711/tcp ghcr.io/i234dev/mymule:latest

Then open http://localhost:4711 and log in with the api_key from config/mymule.conf. Prefer Compose? Use the ready-made docker-compose.yml and run docker compose up -d. More in the Docker guide.

macOS and Linux

With Homebrew:

brew install i234dev/tap/mymule

Settings and downloads are kept in ~/MyMule. Update with brew upgrade mymule.

Windows

With Scoop:

scoop bucket add mymule https://github.com/i234dev/scoop-bucket
scoop install mymule

Settings and downloads are kept in %USERPROFILE%\scoop\persist\mymule. Update with scoop update mymule.

Download

Windows, Linux, macOS and FreeBSD, for Intel/AMD and ARM: get the archive for your system from Releases and unpack it anywhere. MyMule is portable: its settings and downloads live next to the program.

Quick start

Without Docker, start it and use it from the terminal:

mymule start                 # start the engine in the background
mymule search -links ubuntu  # search; -links prints ed2k:// links
mymule add "ed2k://|file|...|/"
mymule top                   # live view (q to quit)
mymule stop

The web interface is off by default outside Docker: set web_ui = true in mymule.conf, restart MyMule and open http://127.0.0.1:4711.

Every release comes with a SHA256SUMS file and a signed build provenance attestation. See the README for configuration, the web interface, running on a server or NAS, and security; the API and the *arr guide have their own pages.

Only use MyMule for content you are allowed to download and share. eD2K is a public network: other users see your IP address and the files you share. Please read the terms of use and disclaimer before using it.
